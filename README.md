\# Hotel Management System



A responsive Hotel Management System developed using React.js, Redux, Node.js, Express.js and PostgreSQL.



\## Features

\- Add, Edit and Delete Hotels

\- Hotel Image Upload and Preview

\- Search by Hotel Title

\- Filter by Price Range

\- Pagination

\- Hotel Details Page

\- Map and Geolocation

\- Responsive User Interface

\- Form Validation



\## Technologies Used

\- React.js

\- Redux Toolkit

\- JavaScript

\- HTML and CSS

\- Node.js

\- Express.js

\- PostgreSQL

\- Multer

\- Native SQL Queries



\## Setup Instructions



\### Backend

1\. Open terminal and navigate to the server folder.

2\. Run `npm install`.

3\. Configure the `.env` file with PostgreSQL credentials.

4\. Run `npm run dev` or `node server.js`.



\### Frontend

1\. Open another terminal and navigate to the client folder.

2\. Run `npm install`.

3\. Run `npm run dev`.

4\. Open the local URL shown in the terminal.



\## API Endpoints

\- GET `/api/hotels`

\- GET `/api/hotels/:id`

\- POST `/api/hotels`

\- PUT `/api/hotels/:id`

\- DELETE `/api/hotels/:id`



\## Database

PostgreSQL database: `hotel\_management\_v18`
